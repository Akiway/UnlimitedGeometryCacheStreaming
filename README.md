# UnlimitedGeometryCacheStreaming

This Cyberpunk 2077 mod modifies the `.geometry_cache` resource as it loads to allow all geometry cache entries to be accessed from anywhere in the world. 

## Requirements
RED4Ext ([Nexus](https://www.nexusmods.com/cyberpunk2077/mods/2380) | [Github](https://github.com/wopss/RED4ext))
Redscript ([Nexus](https://www.nexusmods.com/cyberpunk2077/mods/1511) | [Github](https://github.com/jac3km4/redscript))
Codeware ([Nexus](https://www.nexusmods.com/cyberpunk2077/mods/7780) | [Github](https://github.com/psiberx/cp2077-codeware))
